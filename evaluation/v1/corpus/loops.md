# Perulangan Python

Perulangan `for` mengambil item satu per satu dari iterable. `range(start, stop,
step)` tidak menyertakan nilai `stop`. Pernyataan `continue` melewati sisa badan
loop untuk iterasi saat ini, sedangkan `break` langsung keluar dari loop terdekat.

Blok `else` pada loop dijalankan jika loop selesai tanpa `break`. Jika `break`
dijalankan, blok `else` dilewati.
