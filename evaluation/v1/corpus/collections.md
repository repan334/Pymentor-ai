# Koleksi Python

List adalah koleksi berurutan yang mutable: elemennya dapat ditambah, dihapus,
atau diganti. Tuple juga berurutan, tetapi immutable setelah dibuat.

Dictionary memetakan key unik ke value. Key harus hashable. Pemanggilan
`mapping.get(key)` untuk key yang tidak ada mengembalikan `None` secara default,
atau nilai default kedua jika diberikan, tanpa menimbulkan `KeyError`.
