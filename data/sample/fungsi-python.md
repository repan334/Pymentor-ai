# Fungsi Python

Fungsi didefinisikan menggunakan kata kunci def.

Parameter adalah nama pada definisi fungsi.
Argumen adalah nilai yang diberikan ketika fungsi dipanggil.

Kata kunci return mengakhiri pemanggilan fungsi dan mengembalikan nilai.
Fungsi yang selesai tanpa return eksplisit mengembalikan None.

Contoh:

```python
def double(number):
    return number * 2
```

Pemanggilan double(4) mengembalikan 8.
